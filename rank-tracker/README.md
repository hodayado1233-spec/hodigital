# מעקב ביטויים

מערכת שבודקת פעם ביום באיזה מקום כל לקוח מופיע בגוגל על כל ביטוי, ושומרת היסטוריה.
עלייה מסומנת בירוק, ירידה באדום, ולכל ביטוי מוצג דף הנחיתה שמדורג.

- **הדשבורד:** https://hodayado1233-spec.github.io/hodigital/rank-tracker/
- **תצוגת דוגמה עם נתונים מומצאים:** https://hodayado1233-spec.github.io/hodigital/rank-tracker/?demo=1

## הגדרה חד-פעמית

1. נרשמים ל-[serper.dev](https://serper.dev) ומעתיקים את ה-API Key (יש 2,500 בדיקות חינם, אחר כך בערך דולר לכל 1,000).
2. ב-GitHub: **Settings → Secrets and variables → Actions → New repository secret**
   שם: `SERPER_API_KEY`, ערך: המפתח.
3. כדי להריץ סריקה ראשונה מיד: **Actions → Rank tracker → Run workflow**.

מכאן הסריקה רצה לבד כל בוקר (בסביבות 06:00), והתוצאות נשמרות בתיקייה `data`.

## הוספת לקוח או ביטויים

עורכים את `clients.json` (אפשר ישירות באתר של GitHub, עם העיפרון):

```json
{
  "id": "client-name",
  "name": "שם הלקוח",
  "domain": "example.co.il",
  "keywords": ["ביטוי ראשון", "ביטוי שני"]
}
```

- `id` באנגלית בלבד, בלי רווחים. הוא גם שם קובץ הנתונים, אז לא משנים אותו אחרי שהתחילו לאסוף.
- `domain` בלי `https://` ובלי `www`. תתי-דומיינים נספרים אוטומטית.
- ב-`settings`: `maxDepth` הוא עד איזה מקום בודקים (50 = חמישה עמודים בגוגל). ביטוי שלא נמצא יוצג "לא בטופ 50".

## עלות

כל עמוד תוצאות (10 תוצאות) הוא בדיקה אחת. ביטוי שנמצא בעמוד הראשון עולה בדיקה אחת, ביטוי שלא נמצא עד מקום 50 עולה 5.
לדוגמה: 100 ביטויים, רובם בעמודים הראשונים, יוצאים בערך 150–250 בדיקות ביום, כלומר 5–8 דולר בחודש.

## דוח חודשי ללקוח

בתחתית הדשבורד בוחרים חודש ואז:
- **ייצוא לאקסל (CSV)**: מיקום בתחילת החודש, בסוף החודש, השינוי, השיא ודף הנחיתה.
- **דוח להדפסה / PDF**: דף מעוצב, בחלון ההדפסה בוחרים "שמירה כ-PDF".
