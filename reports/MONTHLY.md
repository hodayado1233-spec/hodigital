# משימה חודשית: בדיקת מיקומים לכל הלקוחות

ההוראות האלה מיועדות ל-Claude Code שרץ **על המחשב של הודיה**, כמשימה מתוזמנת (Local scheduled task) באפליקציית Claude Desktop. הבדיקה חייבת לרוץ מהמחשב שלה: גוגל חוסם חיפושים שמגיעים משרתים בענן.

## השלבים

1. **מעדכנים את הריפו:** `git checkout main && git pull`. אם יש שינויים מקומיים שלא נשמרו ב-commit, עוצרים ומדווחים, ולא דורסים אותם.
2. **קובעים את החודש:** החודש **הקודם** בפורמט `YYYY-MM`. המשימה רצה ב-1 לחודש, ולכן ריצה ב-1.11.2026 בודקת את `2026-10`. אם `reports/data/<client>/<month>.json` כבר מכיל `rankings` עם `checkedAt` מהשבוע האחרון, מדלגים על הלקוח הזה.
3. **מוודאים שהכלים מותקנים:** בתיקייה `tools`, אם אין `node_modules`, מריצים `npm install` ואחר כך `npx playwright install chromium`.
4. **מריצים את הבדיקה:** בתיקייה `tools` מריצים
   ```
   node rank-all.mjs <month> --headed
   ```
   - הבדיקה נפתחת בחלון דפדפן נקי, בלי עוגיות והיסטוריה (כמו גלישה בסתר). יש השהיה של 6–12 שניות בין חיפושים, ולכן היא לוקחת כמה דקות.
   - **אם מופיעה CAPTCHA:** הסקריפט מחכה עד 5 דקות שהודיה תפתור אותה בחלון. אם הלקוח נכשל בגלל זה, מדווחים לה ולא מנסים לעקוף את ה-CAPTCHA. אחרי שהיא מאשרת, מריצים שוב רק את הלקוח הזה: `node rank-check.mjs <client> <month> --headed`.
5. **שומרים:** מוסיפים את `reports/data/` ל-commit עם ההודעה `Rankings <month>` ועושים `git push origin main`.
   - **לא** מוסיפים את החודש ל-`clients.json`. בשלב הזה הדוח עוד חסר נתוני Search Console ו-Analytics, והחודש יתווסף לרשימה רק כשהדוח יהיה מלא.
6. **מסכמים להודיה בעברית:** לכל לקוח כמה ביטויים יש במקומות 1–3, ב-4–10 ובמקום 11 ומעלה, אילו ביטויים עלו או ירדו ב-3 מקומות או יותר לעומת החודש הקודם, ואילו לקוחות נכשלו. בסוף מזכירים לה להעביר את נתוני Search Console ו-Analytics של החודש, כדי להשלים את הדוחות.

## אסור

- לשנות קוד בתיקייה `tools/` או בתבניות ה-HTML. אם משהו לא עובד, מדווחים.
- להוריד את ההשהיות או להריץ כמה בדיקות במקביל.
- לגעת בקבצים של הלקוח `demo`.
