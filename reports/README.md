# סטודיו דוחות SEO חודשיים

מערכת להפקת דוח חודשי ללקוחות קידום אורגני. אין בה תשלום חודשי, אין שרת ואין מסד נתונים.
כל הנתונים מגיעים מכלים חינמיים: Google Search Console,‏ Google Analytics 4, ובדיקת מיקומים שמריצים על המחשב.

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | הסטודיו: רשימת לקוחות, ייבוא נתונים, עריכה והורדת הדוח |
| `report-template.html` | עיצוב הדוח שהלקוח רואה. בלי נתונים הוא מציג את הדוח לדוגמה |
| `samples/demo.json` | נתוני הדוגמה (לקוח בדוי) |
| `tools/rank-check.mjs` | בודק המיקומים בגוגל, רץ בדפדפן נסתר על המחשב שלך |
| `tools/fetch-google.mjs` | מושך את נתוני Search Console ו-GA4 של כל הלקוחות דרך ה-API החינמי של Google |
| `tools/build-report.mjs` | בונה טיוטת דוח מוכנה מכל קובץ month-….json |
| `tools/apps-script/` | הגרסה ל-Google Apps Script: רצה בחשבון ה-Google שלך ושולחת את הדוחות במייל ב-1 לחודש |
| `tools/clients.example.json` | תבנית לרשימת הלקוחות של הסקריפט האוטומטי |

## מה יש בדוח

1. **בשורה התחתונה**: 2–3 משפטים ונקודות בולטות.
2. **ארבעה מספרים מרכזיים** עם השוואה לחודש הקודם: קליקים מגוגל, כניסות ממנועי AI, לידים, וכמה ביטויים בעמוד הראשון.
3. **חיפוש אורגני**: גרף קליקים יומי, חשיפות, CTR, מיקום ממוצע, הביטויים והעמודים המובילים.
4. **מיקומים לביטויי היעד**: מיקום, שינוי מהחודש הקודם, העמוד המדורג, והאם הופיעה סקירת AI של גוגל והאם האתר צוטט בה.
5. **כניסות ממנועי AI**: ChatGPT,‏ Gemini,‏ Perplexity,‏ Copilot,‏ Claude ועוד.
6. **לידים** לפי ערוץ (וואטסאפ, טופס, טלפון).
7. **מגמה לאורך החודשים** (מתמלאת לבד מהחודש השני).
8. **מה עשינו באתר החודש**: יומן פעולות האופטימיזציה.
9. **התוכנית לחודש הבא**.

## איפה זה רץ

הסטודיו הוא דף סטטי. אחרי מיזוג ל-`main` הוא יהיה זמין ב-GitHub Pages:
`https://hodayado1233-spec.github.io/hodigital/reports/`

- הנתונים נשמרים **רק בדפדפן שבו עובדים** (localStorage). בסוף כל חודש לוחצים "הורדת גיבוי" ושומרים את הקובץ בדרייב.
- נתוני הלקוחות **לא** נשמרים בגיטהאב ולא עולים לשום שרת. הדוח שיורד הוא קובץ HTML אחד שהנתונים בתוכו.
- לא לפתוח את `index.html` בלחיצה כפולה מהמחשב: הדפדפן חוסם טעינה של התבנית מקובץ מקומי. עובדים דרך הכתובת של GitHub Pages, או מריצים `npx serve reports` ופותחים את הכתובת שמופיעה.

## העבודה החודשית

בתחילת כל חודש, על החודש שהסתיים. Search Console מעדכן נתונים באיחור של 2–3 ימים, ולכן עדיף לעבוד מה-3 בחודש והלאה.

**במסלול האוטומטי** (אחרי ההגדרה של Apps Script, למטה, ב-1 לחודש מגיע מייל עם הקבצים), או בהרצה מהמחשב:
```bash
cd reports/tools
node fetch-google.mjs                       # כל הלקוחות, החודש הקודם
node rank-check.mjs --domain www.example.co.il --keywords keywords-example-co-il.txt
```
גוררים את כל קובצי `month-….json` ו-`rankings-….json` יחד לאזור **"ייבוא אוטומטי"** בסטודיו. הנתונים מ-Search Console ומ-GA4, הלידים והמיקומים מתמלאים לבד. כל קובץ מיקומים משויך ללקוח לפי הדומיין שבשם הקובץ. נשאר רק לכתוב את יומן האופטימיזציה ואת הסיכום (שלבים 5–6).

**במסלול הידני** (בלי הגדרה, כ-20 דקות ללקוח), עוברים על השלבים הבאים:

### 1. Search Console
**ביצועים ← תוצאות חיפוש** ← טווח תאריכים: החודש הקודם.
מומלץ להפעיל "השוואה" לחודש שלפניו, ואז ההשוואה בדוח מגיעה ישר מגוגל.
**ייצוא ← הורדת CSV** ← גוררים את קובץ ה-ZIP לשלב 1 בסטודיו (לא צריך לחלץ).

### 2. Analytics: כניסות ממנועי AI
**דוחות ← רכישה ← רכישת תנועה**. מחליפים את המימד הראשי ל-`Session source / medium`, טווח: החודש הקודם.
**שיתוף ← הורדת קובץ ← CSV** ← גוררים לשלב 2.
הסטודיו מסכם לבד את כל הכניסות, הכניסות האורגניות, והכניסות מכל מנוע AI.

כדי לראות את זה גם בתוך GA4, אפשר לבנות פעם אחת "חקירה" (Exploration) עם מסנן על Session source שתואם לביטוי הזה:

```
chatgpt|openai|perplexity|gemini\.google|bard\.google|copilot|claude\.ai|deepseek|grok|meta\.ai|you\.com|mistral
```

### 3. מיקומים בגוגל
בגוגל אין דרך חינמית ואמינה לבדוק מיקומים מהענן: שרתים נחסמים מהר ב-CAPTCHA, ושירותי API עולים כסף.
לכן הבדיקה רצה **על המחשב שלך**, בחלון נסתר, כמו בדיקה ידנית, רק אוטומטית.

התקנה (פעם אחת, צריך [Node.js](https://nodejs.org)):
```bash
cd reports/tools
npm run setup
```

כל חודש:
1. בסטודיו, שלב 3 ← "רשימת הביטויים" ← **הורדת keywords.txt** ומעבירים לתיקייה `reports/tools`.
2. מריצים:
   ```bash
   node rank-check.mjs --domain www.example.co.il --keywords keywords-example-co-il.txt
   ```
3. נפתח חלון כרום. אם גוגל מבקש CAPTCHA, פותרים אותו בחלון ולוחצים Enter בטרמינל.
4. גוררים את קובץ ה-`rankings-….json` שנוצר לשלב 3 בסטודיו.

מה הסקריפט עושה: לכל ביטוי פותח חלון נסתר חדש (בלי עוגיות והיסטוריה), מחפש ב-google.co.il בעברית, סורק עד 30 תוצאות אורגניות (בלי מודעות), ורושם את המיקום והעמוד. הוא גם בודק אם הופיעה סקירת AI של גוגל ואם האתר צוטט בה. בין ביטוי לביטוי הוא מחכה 8–18 שניות כדי לא להיחסם, כך ש-20 ביטויים לוקחים כ-5 דקות.

שימו לב: מיקום הוא תמונת מצב מרגע אחד וממקום אחד, ולכן יכול להיות שונה מ"מיקום ממוצע" ב-Search Console. זה תקין. הזיהוי של סקירת ה-AI תלוי במבנה הדף של גוגל, שמשתנה מדי פעם, ולכן כדאי לבדוק אותו ידנית מדי פעם.

### 4. לידים
ממלאים מספר לידים לפי ערוץ. מקורות אפשריים:
- **אירועי מפתח ב-GA4** (מומלץ, חינם): מגדירים ב-Google Tag Manager אירוע לקליק על קישורי `tel:` ו-`wa.me`, ואירוע לשליחת טופס. אחרי זה המספרים נמצאים ב-GA4 תחת "אירועי מפתח".
- מערכת הטפסים של האתר, או המספרים שהלקוח מעביר.

### 5–6. אופטימיזציה, סיכום ותוכנית
יומן הפעולות כדאי למלא לאורך החודש, לא רק בסוף. כל פעולה במשפט שבעל העסק מבין.

### 7. שליחה
**תצוגה מקדימה והורדה** ← קובץ HTML אחד. אפשר:
- לשלוח אותו במייל או בוואטסאפ, והוא נפתח בכל דפדפן.
- לפתוח אותו וללחוץ "הדפסה / שמירה כ-PDF" כדי לשלוח PDF.

## הדרך הקלה: Google Apps Script (מומלץ)

סקריפט שרץ בתוך חשבון ה-Google שלך, בחינם. הוא מתחבר בתור **החשבון שלך**, ולכן רואה כל לקוח שכבר יש לך אליו גישה ב-Search Console וב-Analytics. לא צריך Google Cloud, לא צריך משתמש רובוט ולא צריך להוסיף הרשאות אצל הלקוחות.

ב-1 לכל חודש, בין 8 ל-9 בבוקר, הוא:
- מושך את נתוני החודש הקודם של כל הלקוחות, כולל השוואה לחודש שלפניו;
- שומר טיוטת דוח וקובץ נתונים לכל לקוח בתיקייה "HODIGITAL דוחות חודשיים" בדרייב;
- שולח לך מייל עם סיכום והקבצים מצורפים.

### התקנה (כ-10 דקות, פעם אחת)
1. נכנסים ל-[script.google.com](https://script.google.com) ← **פרויקט חדש**. נותנים לו שם, למשל "דוחות SEO".
2. מוחקים את מה שכתוב בקובץ `Code.gs`, ומדביקים במקומו את כל התוכן של `tools/apps-script/Code.gs`.
3. מציגים את קובץ ההגדרות: גלגל השיניים משמאל (הגדרות הפרויקט) ← מסמנים **"הצגת קובץ המניפסט appsscript.json בעורך"**. חוזרים לעורך, פותחים את `appsscript.json`, ומחליפים את התוכן שלו בתוכן של `tools/apps-script/appsscript.json`.
4. שומרים (Ctrl+S).
5. בתפריט שליד כפתור "הפעלה" בוחרים **listMyProperties** ולוחצים **הפעלה**. בפעם הראשונה Google מבקש אישור: בוחרים את החשבון שלך ← "מתקדם" ← "מעבר אל דוחות SEO" ← אישור. ההודעה "האפליקציה לא אומתה" רגילה, כי זה סקריפט שלך.
6. ב"יומן ההפעלה" שנפתח למטה מופיעים כל הנכסים שלך: כתובות Search Console ומספרי נכסי GA4. מהם ממלאים את הרשימה `CLIENTS` בראש הסקריפט, בלוק אחד לכל לקוח, ושומרים.
7. בוחרים **runMonthly** ← הפעלה. זו ריצת ניסיון: אמור להגיע מייל עם טיוטות הדוחות.
8. בוחרים **setup** ← הפעלה. מעכשיו זה ירוץ לבד בכל 1 לחודש.

אם מופיעה הודעה שצריך "להפעיל את ה-API", פותחים את הקישור שבהודעה, לוחצים **Enable**, ומריצים שוב. זה קורה פעם אחת.

### בכל חודש
מגיע מייל עם הקבצים. מריצים את בודק המיקומים על המחשב, גוררים לסטודיו את קובצי `month-….json` יחד עם `rankings-….json`, וכותבים סיכום ויומן אופטימיזציה.

## דרך מתקדמת: חשבון שירות (הגדרה חד-פעמית)

ה-API של Search Console ושל GA4 חינמי. לא צריך להגדיר חיוב ב-Google Cloud. צריך [Node.js](https://nodejs.org) גרסה 18 ומעלה.

### 1. חשבון שירות (פעם אחת לכל הלקוחות)
1. נכנסים ל-[console.cloud.google.com](https://console.cloud.google.com) ויוצרים פרויקט חדש, למשל `hodigital-reports`.
2. **APIs & Services ← Library**, ומפעילים שני ממשקים: **Google Search Console API** ו-**Google Analytics Data API**.
3. **IAM & Admin ← Service Accounts ← Create service account**. נותנים שם (למשל `reports`) ומדלגים על ההרשאות.
4. נכנסים לחשבון השירות שנוצר ← **Keys ← Add key ← Create new key ← JSON**. הקובץ יורד למחשב.
5. שומרים אותו בשם `service-account.json` בתיקייה `reports/tools`.
   **זה מפתח סודי.** הוא כבר מוחרג מגיט (`.gitignore`). אין לשלוח אותו לאף אחד ואין להעלות אותו לשום מקום.
6. מעתיקים את כתובת המייל של חשבון השירות. היא נראית כך: `reports@hodigital-reports.iam.gserviceaccount.com`.

### 2. גישה לכל לקוח
את חשבון השירות מוסיפים לכל לקוח כמו שמוסיפים משתמש רגיל:
- **Search Console:** הגדרות ← משתמשים והרשאות ← הוספת משתמש ← המייל של חשבון השירות, בהרשאה **מוגבלת**.
- **GA4:** אדמין ← ניהול גישה לנכס ← **+** ← המייל של חשבון השירות, בתפקיד **צופה**.

### 3. רשימת הלקוחות
מעתיקים את `clients.example.json` לקובץ `clients.json` באותה תיקייה וממלאים שורה לכל לקוח:

| שדה | מה לכתוב | איפה מוצאים |
|---|---|---|
| `name` | שם הלקוח כמו שיופיע בדוח | |
| `domain` | הדומיין, למשל `www.example.co.il` | |
| `gscSite` | כתובת הנכס **בדיוק** כמו ב-Search Console: `sc-domain:example.co.il` לנכס דומיין, או `https://www.example.co.il/` (עם `/` בסוף) לנכס קידומת כתובת | בבורר הנכסים בראש Search Console |
| `ga4Property` | מספר הנכס, ספרות בלבד (לא `G-XXXX`) | GA4 ← אדמין ← פרטי הנכס |
| `leadEvents` | אופציונלי: שמות האירועים שנספרים כלידים, ואיך לקרוא להם בדוח | GA4 ← אדמין ← אירועים |

בלי `leadEvents` הסקריפט סופר את כל **אירועי המפתח** (Key events) בנכס, כל אחד בשמו המקורי.
לקוח שאין לו GA4 או Search Console? משמיטים את השדה, והסקריפט ימשוך רק את מה שיש.

### 4. הרצה
```bash
cd reports/tools
node fetch-google.mjs                                   # כל הלקוחות, החודש הקודם
node fetch-google.mjs --month 2026-09                   # חודש מסוים
node fetch-google.mjs --client example.co.il            # לקוח אחד
```
לכל לקוח נוצר קובץ `month-<דומיין>-<חודש>.json`. הקובץ כולל גם את נתוני החודש שלפניו, כך שכבר בדוח הראשון יש השוואה.
אם חסרה הרשאה, הסקריפט אומר בדיוק לאיזה לקוח ומה להוסיף, וממשיך ללקוחות האחרים.

כדי לקבל טיוטת דוח מוכנה לכל לקוח בלי לפתוח את הסטודיו:
```bash
node build-report.mjs        # יוצר draft-report-<דומיין>-<חודש>.html לכל קובץ month-….json בתיקייה
```
טיוטה כוללת את כל המספרים, ואם יש בתיקייה קובץ `rankings-….json` של אותו דומיין, גם את המיקומים. הסיכום ויומן האופטימיזציה נכתבים בסטודיו.

### 5. הרצה אוטומטית בענן ב-1 לכל חודש
Claude מריץ את השאיבה ואת בניית הטיוטות בענן, ב-1 לכל חודש בבוקר, ושולח את הקבצים. לשם כך שומרים שני משתני סביבה בהגדרות של סביבת הענן (תפריט הסביבה בשורת הכותרת של הסשן ← Edit):

| משתנה | מה מכניסים |
|---|---|
| `GOOGLE_SA_KEY` | כל התוכן של קובץ המפתח `service-account.json` |
| `HD_CLIENTS` | כל התוכן של `clients.json` |

אין להדביק את המפתח בצ'אט. הוא נשמר רק בהגדרות הסביבה.

ב-1 לחודש חלק מנתוני Search Console של הימים האחרונים עדיין זמניים, ולכן הסקריפט מושך גם אותם ומסמן זאת. ההבדל מהנתונים הסופיים בדרך כלל זניח. מי שרוצה נתונים סופיים לגמרי יכול להריץ שוב מה-4 בחודש.
