# פלטפורמת דוחות חודשיים – HODIGITAL

דוח חודשי לכל לקוח SEO, שבנוי רק מכלים חינמיים: Google Search Console, Google Analytics 4 ובדיקת מיקומים אוטומטית בדפדפן אנונימי.

- **רשימת הדוחות:** `reports/index.html`
- **דוח בודד:** `reports/report.html?c=<מזהה-לקוח>&m=<YYYY-MM>`
  לדוגמה: `report.html?c=demo&m=2026-09`
- **ייצוא PDF:** בדוח לוחצים על "שמירה כ-PDF / הדפסה" ובוחרים "שמירה כ-PDF".

## איך זה בנוי

```
reports/
  index.html              רשימת לקוחות וחודשים
  report.html             תבנית הדוח (אחת לכל הלקוחות)
  data/
    clients.json          רשימת הלקוחות והחודשים שיש להם דוח
    <client>/keywords.json  הביטויים שבודקים ללקוח והדומיין שלו
    <client>/<YYYY-MM>.json הנתונים של החודש
tools/
  rank-check.mjs          בדיקת מיקומים בגוגל בדפדפן אנונימי
```

כל דוח הוא קובץ JSON אחד. התבנית קוראת אותו ומציירת את הדוח. כדי להוסיף חודש יוצרים קובץ חדש ומוסיפים את החודש ל-`clients.json`. אין שום תשלום, אין מנוי ואין שרת.

## מאיפה מגיע כל נתון (הכול בחינם)

| בדוח | מקור | איפה מוצאים |
|---|---|---|
| כניסות מגוגל, חשיפות, החיפושים המובילים | Search Console | ביצועים → תוצאות חיפוש → חודש אחרון מול החודש הקודם |
| ביקורים אורגניים | GA4 | דוחות → רכישת תנועה → קבוצת ערוצים = Organic Search |
| כניסות מ-AI | GA4 | ראו ההגדרה בהמשך |
| לידים | GA4 (אירוע `generate_lead`) | דוחות → מעורבות → אירועים |
| מיקומים | `tools/rank-check.mjs` | רץ אוטומטית בדפדפן אנונימי |
| אופטימיזציה | יומן העבודה שלך | ממלאים ידנית ב-`optimizations` |

### הגדרה חד-פעמית: כניסות מ-AI ב-GA4

ב-GA4: **ניהול → הצגת נתונים → קבוצות ערוצים → יצירת קבוצת ערוצים חדשה**. מוסיפים ערוץ בשם `AI` עם התנאי *מקור תואם לביטוי רגולרי*:

```
chatgpt\.com|chat\.openai\.com|openai\.com|perplexity\.ai|gemini\.google\.com|bard\.google\.com|copilot\.microsoft\.com|claude\.ai|you\.com|meta\.ai|deepseek\.com|grok\.com
```

גוררים את הערוץ **מעל** Referral, כדי שהכניסות האלה לא ייספרו כהפניה רגילה. מאותו רגע אפשר לראות את הערוץ בדוח רכישת התנועה. כדי לפרק לפי כלי, מסננים לפי הערוץ ומציגים את הממד "מקור".

### הגדרה חד-פעמית: לידים

ב-Google Tag Manager (חינמי) מגדירים טריגר לכל סוג פנייה ושולחים אירוע `generate_lead` עם פרמטר `lead_type`:

- **טופס:** טריגר על הגשת טופס, או על צפייה בעמוד התודה
- **וואטסאפ:** לחיצה על קישור שמכיל `wa.me` או `api.whatsapp.com`
- **טלפון:** לחיצה על קישור שמתחיל ב-`tel:`

ב-GA4 מסמנים את `generate_lead` כאירוע מפתח (Key event). פילוח לפי `lead_type` נותן את "לפי סוג פנייה", ופילוח לפי ערוץ נותן את "לפי מקור הגעה".

## בדיקת מיקומים

גוגל חוסם חיפושים שמגיעים משרתים בענן, ולכן את הבדיקה מריצים מהמחשב שלך.

- **אוטומטית, פעם בחודש (מומלץ):** הבדיקה רצה כמשימה מתוזמנת באפליקציית Claude Desktop. את ההקמה החד-פעמית מתאר [`SETUP-LOCAL.md`](SETUP-LOCAL.md), ואת מה שקורה בכל ריצה מתאר [`MONTHLY.md`](MONTHLY.md).
- **ידנית, דרך Claude in Chrome:** מדביקים את ההנחיה מהקובץ [`claude-in-chrome.md`](claude-in-chrome.md).
- **ידנית, מהטרמינל:** מריצים את הסקריפט שמתואר בהמשך. `rank-all.mjs` בודק את כל הלקוחות ברצף.

הסקריפט פותח Chromium בהקשר חדש לגמרי, כלומר בלי עוגיות, בלי היסטוריה ובלי חשבון (בדיוק כמו חלון גלישה בסתר). הוא מחפש ב-google.co.il בעברית עם `pws=0` (בלי התאמה אישית), עובר על 3 עמודי תוצאות, ומדלג על מודעות ועל תוצאות של גוגל. את המיקום של החודש הקודם הוא לוקח מהדוח הקודם, וכותב רק את החלק `rankings` בקובץ החודש. שאר הנתונים בקובץ לא משתנים.

```bash
cd tools
npm install                                   # פעם אחת
npx playwright install chromium               # פעם אחת
node rank-check.mjs demo 2026-10 --headed     # דסקטופ
node rank-check.mjs demo 2026-10 --mobile     # מובייל
```

כדאי להריץ עם `--headed` מהמחשב שלך. אם גוגל מציג CAPTCHA, פותרים אותו בחלון והבדיקה ממשיכה לבד. בין חיפוש לחיפוש יש השהיה של 6–12 שניות כדי לא להיחסם, ולכן 30 ביטויים לוקחים בערך 5 דקות. אם צריך עוד בדיקה, Search Console נותן "מיקום ממוצע" לכל חיפוש, והוא מופיע בדוח בטבלת "החיפושים שהביאו הכי הרבה כניסות".

## התהליך החודשי (בערך 20 דקות ללקוח)

1. בתחילת החודש מריצים את `rank-check.mjs <client> <YYYY-MM>`.
2. מעתיקים מ-Search Console ומ-GA4 את המספרים של החודש ושל החודש הקודם אל `kpis`, `trend`, `ai`, `leads`, `topQueries`.
3. ממלאים את `optimizations` (מה נעשה) ואת `nextSteps` (מה מתוכנן).
4. כותבים 2–3 משפטים ב-`summary`.
5. מוסיפים את החודש ל-`clients.json`, עושים commit, ושולחים ללקוח קישור או PDF.

אפשר גם לבקש מ-Claude: "תכין את הדוח של <לקוח> לחודש <X>" ולצרף צילומי מסך או ייצוא CSV מ-Search Console ומ-GA4. Claude יריץ את בדיקת המיקומים וימלא את הקובץ.

## לקוח חדש

1. יוצרים תיקייה `reports/data/<client-id>/` (רק אותיות באנגלית, ספרות ומקפים).
2. יוצרים בה `keywords.json` עם `domain` ורשימת `keywords`.
3. מוסיפים את הלקוח ל-`data/clients.json`.

## פרטיות

האתר מתפרסם ב-GitHub Pages, ולכן כל קובץ בריפו ציבורי (פתוח לכל מי שיודע את הכתובת). לדפי הדוחות יש `noindex`, אבל זה רק מונע את הופעתם בגוגל. מי שמחזיק בקישור יכול לפתוח אותם. אם הנתונים רגישים, אפשר לבחור באחת מהאפשרויות:
- להשתמש במזהה לקוח שקשה לנחש (למשל `acme-7f3k9q` ולא `acme`) ולא לקשר אל `reports/` מהאתר.
- לשלוח ללקוח רק PDF ולשמור את הריפו פרטי.

## צפייה מקומית

התבנית טוענת קבצי JSON, ולכן כשפותחים אותה מהמחשב צריך שרת מקומי:

```bash
cd tools && npm run serve      # ואז http://localhost:8080/reports/
```
