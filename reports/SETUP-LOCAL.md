# הקמה חד-פעמית: בדיקת מיקומים אוטומטית מהמחשב

המטרה: פעם בחודש, Claude באפליקציית Claude Desktop פותח לבד דפדפן נקי על המחשב שלך, בודק את המיקומים של כל הלקוחות ושומר אותם בדוחות. הבדיקה חייבת לרוץ מהמחשב שלך, כי גוגל חוסם חיפושים שמגיעים משרתים בענן.

## מה צריך לעשות (בערך 10 דקות)

1. פותחים את אפליקציית **Claude Desktop** ועוברים ללשונית **Code**.
2. לוחצים על **+ New**. מעל תיבת ההודעה, בבורר הסביבה (הסמל של הענן), בוחרים **Local**.
3. בוחרים תיקייה, למשל **Documents** (מסמכים).
4. מדביקים את ההודעה שבהמשך ושולחים. Claude יבקש אישורים בדרך. מאשרים, ומסמנים "always allow" כשמופיעה האפשרות.
5. אם נפתח דפדפן שמבקש להתחבר ל-GitHub, מתחברים. זה צריך לקרות רק פעם אחת.

אם Windows מבקש אישור להתקנה (Git או Node.js), מאשרים.

## ההודעה להדבקה

```
אני רוצה להקים על המחשב הזה בדיקת מיקומים חודשית בגוגל ללקוחות שלי. תעשה את השלבים לפי הסדר ותעצור אם משהו נכשל.

1. בדוק אם Git ו-Node.js (גרסה 20 ומעלה) מותקנים: git --version ו-node --version.
   אם חסר משהו:
   - ב-Windows התקן עם winget: winget install --id Git.Git -e ו-winget install --id OpenJS.NodeJS.LTS -e, ואחר כך פתח טרמינל חדש כדי שהפקודות יוכרו.
   - ב-Mac, אם יש Homebrew: brew install git node. אם אין, תגיד לי מה להוריד מ-nodejs.org.
2. שכפל את הריפו https://github.com/hodayado1233-spec/hodigital לתיקייה hodigital בתוך התיקייה הנוכחית (ואם הוא כבר קיים שם, עשה git pull) ועבור ל-main.
3. בתיקייה tools הרץ: npm install ואחר כך npx playwright install chromium.
4. בדיקת ניסיון שלא שומרת כלום:
   node rank-check.mjs demo 2026-09 --headed --pages=1 --dry-run
   ייפתח חלון של דפדפן. המטרה היא רק לוודא שגוגל מחזיר תוצאות ולא חוסם. (הדומיין של demo הוא אתר דמה, ולכן מיקום "-" זה תקין.)
   אם מופיעה CAPTCHA, תגיד לי ואני אפתור אותה בחלון.
5. ודא שאפשר לדחוף ל-GitHub: הרץ git push --dry-run origin main. אם צריך להתחבר, תנחה אותי.
6. צור משימה מתוזמנת מקומית (Local scheduled task):
   - שם: monthly-rank-check
   - תיקייה: תיקיית hodigital ששכפלת
   - לוח זמנים: ב-1 לכל חודש בשעה 09:00
   - הוראות: "בצע את ההוראות שבקובץ reports/MONTHLY.md בתיקייה הזו."
7. הפעל את המשימה פעם אחת עם Run now, כדי שאוכל לאשר את ההרשאות ב-always allow, ואחר כך סכם לי מה הוקם.

בסוף תזכיר לי להפעיל ב-Settings > This computer > System את Keep computer awake, כי המשימה רצה רק כשהמחשב דולק והאפליקציה פתוחה.
```

## מה קורה בכל חודש

- ב-1 לחודש בבוקר המשימה מתחילה לרוץ לבד, וקופצת התראה על המחשב. אם המחשב היה כבוי באותו בוקר, המשימה תרוץ ברגע שתדליקי אותו.
- אם גוגל מציג CAPTCHA, החלון נשאר פתוח ואת פותרת אותה.
- בסוף מקבלים סיכום: מי עלה, מי ירד ואיזה לקוח נכשל. המיקומים נשמרים בדוחות ונדחפים ל-GitHub.
- שולחים ל-Claude Code את נתוני Search Console ו-Analytics, והוא משלים את הדוחות.

## הוספת לקוח

מספיק לבקש מ-Claude: "תוסיף לקוח חדש: <שם>, הדומיין <דומיין>, והביטויים: ...". הוא ייצור את `reports/data/<id>/keywords.json` ויוסיף את הלקוח ל-`clients.json`. מהחודש הבא המשימה החודשית תבדוק גם אותו.
