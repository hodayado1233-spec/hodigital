# בדיקת מיקומים עם Claude in Chrome

Claude in Chrome בודק את הביטויים בדפדפן שלך, שמחובר מהכתובת הביתית שלך, ולכן גוגל לא חוסם אותו כמו שהוא חוסם שרתים בענן. בסוף הבדיקה מקבלים בלוק JSON, ומדביקים אותו בשיחה עם Claude Code. משם הוא נכנס לדוח החודשי.

## הכנה חד-פעמית

1. מתקינים את התוסף Claude מחנות התוספים של Chrome ומתחברים לחשבון.
2. **מאפשרים לתוסף לעבוד בגלישה בסתר:** נכנסים ל-`chrome://extensions`, לוחצים על **פרטים** של התוסף Claude ומדליקים את **אפשר במצב גלישה בסתר**.
3. בכל חודש פותחים **חלון גלישה בסתר** (Ctrl+Shift+N, או ב-Mac ‏Cmd+Shift+N), פותחים בו את הפאנל של Claude ומדביקים את ההנחיה שבהמשך.

אם הפאנל לא נפתח בגלישה בסתר, אפשר לעבוד גם בחלון רגיל. הכתובת בהנחיה כוללת `pws=0`, שמבטל את ההתאמה האישית של התוצאות, אבל עדיף בגלישה בסתר.

## ההנחיה להדבקה

מחליפים את שלושת הפרטים שבסוגריים המרובעים: הדומיין, המכשיר ורשימת הביטויים. את הרשימה של כל לקוח אפשר להעתיק מהקובץ `reports/data/<לקוח>/keywords.json`.

```
אני צריכה שתבדוק מיקומים אורגניים בגוגל ישראל לאתר אחד.

הדומיין שלי: [example.co.il]
מכשיר: [דסקטופ]
הביטויים (ביטוי אחד בכל שורה):
[שיפוץ דירות בתל אביב
קבלן שיפוצים
שיפוץ מטבח]

לכל ביטוי, לפי הסדר:
1. פתח את הכתובת הזו (כש-<ביטוי> מקודד ל-URL):
   https://www.google.co.il/search?q=<ביטוי>&hl=iw&gl=il&pws=0
2. מצא את התוצאה האורגנית הראשונה ששייכת לדומיין שלי. גם תת-דומיין וגם www נחשבים שלי.
3. ספירת המיקום: סופרים רק תוצאות אורגניות רגילות (כותרת כחולה, כתובת ותיאור), מלמעלה למטה, ומתחילים מ-1.
   לא סופרים: מודעות ("ממומן"), סקירת AI (AI Overview), המפה ורשימת העסקים שלה, "אנשים שואלים גם", סרטונים, תמונות, חדשות, "חיפושים קשורים", וקישורים פנימיים (sitelinks) שמופיעים מתחת לתוצאה.
   אם אותו אתר מופיע פעמיים ברצף, כל הופעה נספרת כתוצאה נפרדת.
4. אם האתר שלי לא בעמוד 1, עבור לעמוד הבא (הכפתור "הבא", או &start=10 ואחר כך &start=20) והמשך לספור מאיפה שעצרת. בודקים עד 3 עמודים, כלומר עד מיקום 30 בערך.
5. בנוסף לכל ביטוי, בדוק בעמוד הראשון:
   - האם האתר שלי מצוטט בתוך סקירת ה-AI (aiOverview: true/false, ו-false אם אין סקירה בכלל)
   - האם האתר שלי מופיע ברשימת העסקים שליד המפה (localPack: true/false)
6. חכה 5–10 שניות לפני שאתה עובר לביטוי הבא.

אם גוגל מציג CAPTCHA או "זיהינו תנועה חריגה", עצור ותגיד לי. אני אפתור אותו ואז תמשיך מאותו ביטוי. אל תנסה לעקוף את זה בעצמך.
אל תלחץ על מודעות, ואל תיכנס לתוצאות עצמן. מספיק לקרוא את עמוד התוצאות.

בסוף, החזר רק בלוק JSON אחד בדיוק בפורמט הזה, בלי שום טקסט נוסף:
{
  "checkedAt": "YYYY-MM-DD",
  "engine": "google.co.il",
  "device": "desktop",
  "keywords": [
    { "keyword": "הביטוי", "position": 7, "url": "/הנתיב-של-העמוד", "aiOverview": false, "localPack": false }
  ]
}

כללים לשדות:
- position: מספר שלם. אם האתר לא נמצא ב-3 העמודים, כותבים null.
- url: רק הנתיב של העמוד שדורג (למשל "/kitchen", ובעמוד הבית "/"). אם האתר לא נמצא, כותבים null.
- device: "desktop" או "mobile".
- checkedAt: התאריך של היום.
```

## אחרי הבדיקה

מעתיקים את ה-JSON שקיבלת ושולחים אותו ל-Claude Code עם הודעה כמו: "מיקומים של <לקוח> לחודש 2026-10". Claude Code מכניס את המיקומים לקובץ הדוח, ממלא את המיקום של החודש הקודם (`prev`) מהדוח הקודם, ומחשב את השינוי.

## בדיקה במובייל

אם רוצים לבדוק גם מובייל: פותחים את כלי המפתחים (F12), לוחצים על סמל הטלפון (Toggle device toolbar) ומרעננים את הדף. בהנחיה כותבים `מכשיר: מובייל` ו-`"device": "mobile"`.
